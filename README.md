# EVIL Collector Releases

Fertige Collector-Pakete und signierte Update-Informationen für SimHub. Quellen, Zugangsdaten, private Schlüssel, Rohproben und Debug-Dateien werden hier nicht veröffentlicht.

## Aktuelle Vorschau: RC.17

**0.3.23-iracing-rc.17** ergänzt den nativen Zeitanker lokaler iRacing-IBTs für die belegte Zuordnung zu API 0.34.1. Alle 28 zuvor vorgemerkten Abschnitte sind gespeichert und per Download geprüft; die Warteschlange ist leer. [Änderungen und Updateanleitung](release-notes/rc17.md) · [Prüfnachweis](release-notes/rc17-evidence.json).

SimHub → **Additional plugins → EVIL Motorsport Telemetry → Updates → Vorschau – RC-Versionen (bewusst wählen) → Nach Updates suchen**. Erwartet: **0.3.23-iracing-rc.17**. Danach **Herunterladen und prüfen → Update installieren**. Spiele vorher schließen. Für den direkten Updateweg wird Helfer 2.0.0 benötigt.
